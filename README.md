# 📄 Resume Screening Assistant using NLP & Machine Learning

## 📌 Project Overview

The Resume Screening Assistant is a Machine Learning web application that classifies resumes into different job categories using Natural Language Processing (NLP). Users can upload resumes in PDF, DOCX, or TXT format, and the application predicts the most likely job category.

---

## 🚀 Features

* Upload resumes in PDF, DOCX, and TXT formats
* Extract text from uploaded resumes
* Clean and preprocess text using NLP
* Predict resume category using a Machine Learning model
* Display prediction confidence
* Show the top 5 predicted categories
* Interactive web interface built with Streamlit

---

## 🛠️ Technologies Used

* Python
* Streamlit
* Scikit-learn
* Pandas
* NumPy
* NLTK
* PyPDF
* python-docx
* Joblib

---

## 📂 Dataset

* Updated Resume Dataset
* Approximately 960 resumes
* Multiple job categories for training and evaluation

---

## 🤖 Machine Learning Workflow

1. Data Collection
2. Data Cleaning
3. Text Preprocessing
4. TF-IDF Vectorization
5. Model Training
6. Resume Classification
7. Prediction using Streamlit

---

## 📊 Model

* TF-IDF Vectorizer
* Logistic Regression Classifier

---

## 📈 Output

The application displays:

* Predicted Job Category
* Prediction Confidence
* Top 5 Category Probabilities
* Extracted Resume Text

---
